# lavasec-doc — retired

This documentation repository is retired and no longer maintained. Its contents
are kept for historical reference and may not reflect how Lava works today.

**The code is the source of truth.** For current implementation, tests, build
instructions, and contributions, start with our public repositories:

- [Lava for iOS](https://github.com/lavasecurity/lavasec-ios) — the public app
  source, including its filtering engine and tests.
- [Lava for Android](https://github.com/lavasecurity/lavasec-android) — the Android
  codebase.
- [Lava Security on GitHub](https://github.com/orgs/lavasecurity/repositories?type=public)
  — all currently public repositories.

For an explanation of your own setup, open **Explore** in the Lava app. Visit
[Support](https://lavasecurity.app/support/) for common questions and ways to get
in touch. Report code issues in the relevant public code repository.

This repo and the former docs site are not an authoritative product manual or
feature contract. Refer to the code and tests for the version you are using.
